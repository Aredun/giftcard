# ULTEBRA Christmas Gift Card

A small static web page: choose one of three gift cards, enter your work e-mail address, and get a selection code that is computed locally in your browser. Send the code to ULTEBRA to receive your gift card. Nothing is stored and nothing is sent anywhere by the page itself.

**Open the page:** https://aredun.github.io/giftcard/

The source is maintained in Azure DevOps; this repository only holds the published page.
